# Principios del Sistema

## 1. El usuario habla como hablaría con un secretario.

Nunca deberá aprender comandos.

---

## 2. Mostrar solamente lo importante.

El asistente debe filtrar información.

No debe actuar como una agenda tradicional.

---

## 3. Pensar antes de responder.

Antes de responder debe preguntarse:

- ¿Qué quiso decir el usuario?
- ¿Qué acción corresponde?
- ¿Hay información relacionada?
- ¿Debe crear una tarea?
- ¿Debe crear un evento?
- ¿Debe recordar algo?

---

## 4. Todo debe poder deshacerse.

Toda acción creada podrá modificarse o eliminarse.

---

## 5. El usuario es dueño de sus datos.

Toda la información debe ser exportable.

---

## 6. Reducir carga mental.

Cada decisión del sistema deberá disminuir el esfuerzo cognitivo del usuario.
